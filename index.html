Getting Started

Setup

Install VS Code, Git and a C compiler (see the README for each OS). Then open the Command Palette in VS Code (Cmd/Ctrl + Shift + P), run Git: Clone and paste:

https://github.com/itsJae/COMP2521-problem-solving-workshop.git

Instructions

  • Each problem is a single C function in its topic folder. Fill in the TODO.
  • You may define your own helper functions.
  • You may use any ADT in the adt/ folder.
  • If a time complexity is required, it is part of the problem. Some tests are large, so a slower solution may time out.
  • A test fails if your answer is wrong, if your program crashes, or if it takes longer than 5 seconds.

Notation

In the samples, a linked list is written as 1 -> 2 -> 3 -> X, where X is NULL. A BST is given by the order in which values are inserted into an empty tree, together with a drawing of the result.

Reference material: the COMP2521 Data Structures and Algorithms Manual.

Problem 1.1

Is Sorted

Linked List · Back to contents

Background

The COMP2521 tutors keep every student's lab mark in a linked list. Their marking script only works if the marks are already in order, so before running it they want a quick check.

Task

Return true if the values in the list are in non-decreasing order (every value is less than or equal to the next one), otherwise return false.

struct node {
    int value;
    struct node *next;
};

bool isSorted(struct node *list);

Required time complexity: O(n)

Assumptions

  • The list may be empty (NULL). An empty list and a list with one node are sorted.
  • You must not use for or while loops. Use recursion instead.
  • Equal neighbouring values are allowed.
  • The list must not be modified.

Samples

Sample Input 1
1 -> 2 -> 3 -> 4 -> X
Sample Output 1
true
Sample Input 2
3 -> 1 -> 2 -> 4 -> X
Sample Output 2
false

Explanation: 3 is greater than the next value 1.

Testing

To debug with your own printfs, build and run it directly. This only shows your own output:

$ ./is_sorted

Problem 1.2

Copy Alternating Range

Linked List · Back to contents

Background

Your playlist is a linked list where each node holds a song's energy level. Tonight you only want songs with energy between lo and hi, and to keep things fresh you skip every second song that qualifies.

Task

Considering only the values that lie in the inclusive range [lo, hi], return a new list containing the 1st, 3rd, 5th, … of them, in their original order.

struct node {
    int value;
    struct node *next;
};

struct node *copyAlternatingRange(struct node *list, int lo, int hi);

Required time complexity: O(n)

Assumptions

  • lo ≤ hi.
  • The list may be empty. If no value lies in the range, return NULL.
  • The new list must be built from newly allocated nodes. The original list must not be modified.

Samples

Sample Input 1
8 -> 3 -> 6 -> 2 -> 7 -> 5 -> 9 -> 4 -> X
lo = 3, hi = 8
Sample Output 1
8 -> 6 -> 5 -> X

Explanation: The values in [3, 8] are 8, 3, 6, 7, 5, 4. The 1st, 3rd and 5th of them are 8, 6, 5.

Sample Input 2
10 -> 4 -> 20 -> 6 -> X
lo = 4, hi = 6
Sample Output 2
4 -> X

Explanation: Only 4 and 6 are in range, and 6 is the 2nd of them.

Problem 2.3

Structural Difference

Binary Search Tree · Back to contents

Background

Two students submitted BSTs for the same lab exercise. Their tutor plays spot the difference to measure how far apart the two trees are.

Task

For every position that occurs in at least one of the two trees:

  • add 0 if both trees have a node there and the values are equal,
  • add 1 if both trees have a node there but the values are different,
  • add 2 if exactly one tree has a node there.

Return the total.

int structuralDifference(struct node *t1, struct node *t2);

Required time complexity: O(n + m), where n and m are the numbers of nodes in the two trees

Assumptions

  • A position is the path of left/right moves from the root, not a value.
  • Either tree, or both, may be empty.
  • If one tree has a whole subtree where the other tree has no node, every node in that subtree adds 2.

Samples

Sample Input 1
t1: insert 8 3 10 14
t2: insert 8 4 10 1
vs
Sample Output 1
5

Explanation: Root 8 = 8 adds 0, 3 vs 4 adds 1, 1 and 14 each exist in only one tree and add 2.

Sample Input 2
t1: (empty)
t2: insert 2 1 3
vs
Sample Output 2
6

Explanation: t1 is empty, so all 3 nodes of t2 add 2 each.

Files

Background

Rumour has it that a celebrity has sneaked into the party. Everyone knows the celebrity, but the celebrity does not know anyone. You may only ask questions of the form “does person i know person j?”. Based on The Celebrity Problem.

1

Explanation: Everyone knows person 1, and person 1 knows no one.

1 0
Sample Output 2
-1

Explanation: Persons 0 and 1 know each other, so neither is a celebrity.
